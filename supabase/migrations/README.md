# Database migrations

Apply SQL migrations from this directory in timestamp order to the configured Supabase project. The first creates requester-owned tickets. The second adds the trusted staff allowlist, shared queue access, status updates, and verified staff email snapshots. The third adds private ticket attachments and requester/staff storage policies. The fourth adds staff assignment. The fifth adds ticket conversations. Migrations 006–012 add the asset register, ticket-to-asset links, ticket priority and reopening, mosque/client-site links, and the client directory. Migration 013 adds device monitoring. Migrations 014–016 refine asset categories and ticket types and categories. Migration 017 adds sustained endpoint health alerts and ticket links. Migration 018 adds database support for optional offline alerts; no scheduled check is configured. Migration 019 adds Windows Defender and pending-restart health details. Run each file once in the Supabase SQL Editor.
